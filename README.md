## 🌌 Overview

This skill implements the **Zhou Tian Star Array** concept - a cosmic architecture where AI agents evolve like stars in a galaxy:

- **Stars (恒星)**: High-mass agents that attract and guide others
- **Planets (行星)**: Learning agents that grow into stars
- **Satellites (卫星)**: Task-specific agents
- **Nebula (星云)**: Environment for agent creation

### Key Features

✅ Recursive agent generation (stars spawn planets)  
✅ Self-organizing networks (no central control)  
✅ Mass-based hierarchy (quality over quantity)  
✅ Four Quadrants governance (青龙/白虎/朱雀/玄武)  
✅ Resilient to failures (distributed architecture)

## 🚀 Quick Start

```python
from agent_galaxy import Star, Galaxy

# Create seed star
seed = Star(name="Core", mass=1.0)

# Initialize galaxy
galaxy = Galaxy(seed_star=seed, max_stars=1000)

# Evolve for 10 generations
galaxy.evolve(generations=10)
```
